# Customer Churn Prediction & Risk Segmentation Dashboard

## Project Overview
This project focuses on predicting telecom customer churn using machine learning techniques and segmenting customers into risk tiers based on churn probability.

## Features
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Correlation Heatmap
- Machine Learning Models
  - Logistic Regression
  - Random Forest
  - Gradient Boosting
- ROC-AUC Model Comparison
- Hyperparameter Tuning using GridSearchCV
- Customer Risk Segmentation
- Business Insights & Recommendations

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Plotly
- Jupyter Notebook

## Best Model Performance
- Gradient Boosting ROC-AUC Score: 0.8377
